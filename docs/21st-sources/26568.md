# Vertical Testimonials Marquee — Default
A vertically scrolling, auto-animating column of testimonial cards with pause-on-hover and edge fade masks, ideal for social-proof sections on landing pages.

install: npx shadcn@latest add "https://21st.dev/r/shadcnspace/marquee-03?api_key=$API_KEY_21ST"
